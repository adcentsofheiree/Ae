## English

Ae is a set of text files that an agent works through to carry out an assignment.

It is for everyone, in literally any field: personal life, relationships, projects, code, knowledge, business, software, the physical world, or anything else.

**How to use it:** give the document to your agent. The last page is written for it: it will help you build your first Ae.

**Contributing:** issues and pull requests are welcome.
